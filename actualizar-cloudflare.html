Versión 2026-10-26-private-payment-test. El código no contiene claves ni cupones.

1. Copia el Worker completo

Ver o seleccionar el código manualmente

En Cloudflare abre oda-pagos → Editar código → worker.js. Reemplaza el contenido y pulsa Implementar.

Conserva tus secretos, la conexión DB y las variables actuales de producción. No cambies Mercado Pago ni Skydropx a modo de pruebas. Esta actualización del cupón utiliza la tabla store_settings existente y no agrega una migración.

2. Comprueba la versión

Abre el estado de Cloudflare. Debe mostrar 2026-10-26-private-payment-test y payments_enabled: true.

3. Genera tu cupón privado

Entra a Administrador → Configuración y busca Prueba privada de $1 MXN. Pulsa Generar cupón privado. El código se guarda solo en ese formulario; en el servidor se almacena su hash. Vence en una hora y permite un pedido.

Completa nombre y correo del comprador, acepta el importe de $1 MXN y pulsa Preparar enlace de $1 MXN. Abre Mercado Pago y revisa el total antes de autorizar el pago. El proveedor puede rechazar un importe tan pequeño; el sistema nunca lo aumenta por su cuenta.

La prueba no incluye producto, fabricación, existencias, envío ni guía. No prueba la cotización o compra de guías de Skydropx. El cupón requiere acceso al administrador y no funciona en el checkout público.

4. Verifica el resultado

Después de pagar, revisa la página de estado y el apartado Ventas del administrador. Debe indicar prueba privada de $1 y pago aprobado. No repitas el pago si aparece pendiente o en revisión. Si el enlace no se confirma, consulta el pedido antes de crear otro cupón.
