Configura Skydropx en pruebas.

Este código conserva el catálogo y Mercado Pago. Skydropx es el único proveedor de envíos. No contiene tus claves.

1. Copia el Worker completo

Cargando código…

Ver o seleccionar el código manualmente

En Cloudflare abre oda-pagos → Editar código → worker.js. Reemplaza todo el contenido con este código y pulsa Implementar. Conserva la conexión a la base de datos D1.

2. Ajusta estas variables de texto

NombreValor
SHIPPING_PROVIDERskydropx
SKYDROPX_MODEtest
SKYDROPX_LABEL_PURCHASES_ENABLEDfalse

Agrega LABEL_PURCHASES_ENABLED=false. Conserva MP_MODE=test y los cobros públicos desactivados mientras comprobamos las cuentas.

En Skydropx Sandbox, obtén las claves de prueba y guárdalas como secretos SKYDROPX_TEST_CLIENT_ID y SKYDROPX_TEST_CLIENT_SECRET. No reutilices las claves de producción.

El servidor confirmado en tu documentación es https://sb-pro.skydropx.com. Guárdalo como SKYDROPX_TEST_API_URL (solo https://servidor, sin /api/v1). El sistema no usa producción si falta esta configuración. Puedes eliminar ENVIA_TOKEN; ya no se utiliza.

3. Comprueba la conexión

En el administrador pulsa Comprobar Skydropx (sin comprar guía). Después verifica origen, existencias, peso y medidas de los paquetes antes de cotizar desde la tienda.

Las cotizaciones de Sandbox se marcan PRUEBA y solo pueden usarse con Mercado Pago en pruebas. La compra de guías sigue desactivada. La conexión real todavía debe comprobarse con las credenciales del Sandbox.
